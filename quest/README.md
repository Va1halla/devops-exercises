# DevOps Quest

Игровой тренажёр по вопросам этого репозитория: все вопросы из `README.md` и `topics/` превращены в карточки
с опытом, уровнями, достижениями и интервальными повторениями.

## Как играть

- **Карта тем**: 54 темы, у каждой свой уровень освоения от «Разведка» до «Мастер».
- **Сессия**: 10 карточек. Сначала ответь сам, потом открой ответ (`Пробел`) и честно оцени себя:
  `1` не знал, `2` частично, `3` знал.
- **Интервальные повторения**: карточка, на которую ты ответил «Знал», вернётся через 1, 3, 7, 14, 30 и 60 дней.
  «Не знал» возвращает её в начало.
- **XP и ранги**: от «Стажёра» до «Легенды DevOps». Ответы «Знал» подряд дают комбо-множитель.
- **Аптайм**: сколько дней подряд ты занимаешься. Дневная цель (SLO) настраивается в профиле.
- **Боссы**: когда увидишь половину карточек темы, открывается экзамен из 15 вопросов. 80% «Знал» дают значок темы.
- **Практика**: упражнения из репозитория можно отмечать выполненными, каждое даёт 50 XP.
- **Достижения**: 26 штук, от «Hello, World» до «Аптайм 30 дней».

Прогресс хранится в браузере (localStorage). В профиле его можно скопировать и перенести на другое устройство.

## Запуск

Онлайн: после включения GitHub Pages (Settings → Pages → Source: GitHub Actions) тренажёр публикуется
по адресу `https://<user>.github.io/devops-exercises/quest/` при каждом пуше в `master`.

Локально, из корня репозитория:

```
python3 scripts/build_quest.py
python3 -m http.server 8000
```

и открыть http://localhost:8000/quest/

## Обновление вопросов

Карточки собираются скриптом `scripts/build_quest.py` из блоков `<details><summary>` во всех Markdown-файлах.
После изменения вопросов запусти его снова. Прогресс привязан к тексту вопроса, поэтому правки в других местах
файла его не сбрасывают.
