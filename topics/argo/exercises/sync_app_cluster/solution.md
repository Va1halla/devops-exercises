# Синхронизация приложения — кластер

## Требования

1. Нужен работающий кластер Kubernetes с установленным ArgoCD
1. Нужно приложение, развёрнутое в кластере и отслеживаемое ArgoCD

## Задачи

1. Убедитесь, что приложение отслеживается ArgoCD и синхронизировано (in sync)
2. . Измените приложение, выполнив команду `kubectl`. Изменение может быть любым:
   1. Изменить тег образа
   2. Изменить количество реплик
   3. Можно пойти на крайние меры и удалить ресурс, если хочется :)
3. Проверьте состояние приложения в ArgoCD
4. Синхронизируйте состояние приложения

## Решение

### UI

1. Нажмите на приложение в UI
   1. Убедитесь, что оно синхронизировано и находится в состоянии "healthy"
2. Внесите изменение в кластере
   1. `kubectl scale --replicas=0 <DEPLOYMENT_NAME>`
   2. `kubectl get rs <DEPLOYMENT_NAME>`
3. Вернитесь в UI и проверьте состояние приложения
   1. Если оно всё ещё в состоянии in sync, нажмите "Refresh"
   2. Приложение должно перейти в состояние "out-of-sync"
   3. Нажмите "Sync", а затем "Synchronize"

### CLI 

```
# Проверить состояние приложения и убедиться, что оно синхронизировано
argocd app get app-demo

# Выполнить следующие команды k8s (или любые другие, меняющие состояние приложения)
kubectl scale --replicas=0 <DEPLOYMENT_NAME>
kubectl get rs <DEPLOYMENT_NAME>

# Снова проверить состояние приложения
argocd app get app-demo

# Синхронизировать состояние приложения
argocd app sync app-demo
argocd app wait app-demo
```
