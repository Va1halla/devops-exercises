## Развёртывание в Kubernetes

Примечание: это упражнение можно решить разными способами. Описанное здесь решение — лишь один из возможных вариантов.

1. Установите Jenkins на одну систему (по стандартной процедуре установки Jenkins)
2. Разверните Kubernetes на удалённом хосте (minikube — простой способ это сделать)
3. Создайте простое веб-приложение или [страницу](html)

4. Создайте [ресурсы](helloworld.yml) Kubernetes - Deployment, Service и Ingress (для доступа по HTTPS)
5. Создайте [инвентарь Ansible](inventory) и укажите в нём адрес кластера Kubernetes
6. Напишите [плейбук Ansible](deploy.yml) для развёртывания ресурсов Kubernetes, а также для генерации 
7. Создайте [конвейер](Jenkinsfile)

8. Запустите конвейер :)
9. Попробуйте обратиться к веб-приложению удалённо
