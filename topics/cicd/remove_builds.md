### Jenkins - удаление заданий (jobs)

#### Цель 

Научиться писать скрипт Jenkins, который работает со сборками (builds), удаляя сборки старше X дней.

#### Инструкции

1. Выберите (или создайте) задание, у которого есть сборки старше X дней
2. Напишите скрипт, удаляющий только сборки старше X дней

#### Подсказки

X может быть любым. Например, удалите сборки старше 3 дней. Главное — не удаляйте просто все сборки (это не соответствует цели).
