# DNS

[Wikipedia](https://en.wikipedia.org/wiki/Domain_Name_System): «Прежде всего, она преобразует легко запоминаемые доменные имена в числовые IP-адреса, необходимые для поиска и идентификации компьютерных сервисов и устройств с помощью базовых сетевых протоколов.»

Иными словами, самый распространённый вариант использования DNS — преобразование адресов. Это может быть преобразование имени хоста в IP-адрес и наоборот — IP-адреса в имя хоста.
Кроме того, DNS можно использовать для балансировки нагрузки с помощью техники round robin.
