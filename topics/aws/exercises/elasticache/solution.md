## AWS ElastiCache

### Цели

1. Создать ElastiCache Redis
  * Тип экземпляра — "cache.t2.micro"
  * Количество реплик — 0

### Решение

#### Консоль

1. Перейти в сервис ElastiCache
2. Нажать "Get Started Now"
3. Выбрать "Redis"
4. Ввести имя и описание
5. Выбрать "cache.t2.micro" в качестве типа узла
6. Установить количество реплик 0
7. Создать новую группу подсетей (subnet group)
8. Нажать "Create"
