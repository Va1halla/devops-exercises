## AWS Auto Scaling Groups - политика динамического масштабирования (Dynamic Scaling Policy)

### Требования

1. Существующая Auto Scaling Group с максимальной ёмкостью не меньше 3
2. Один работающий экземпляр EC2 с не более чем 4 CPU

### Цели

1. Создать политику динамического масштабирования со следующими параметрами
  1. Отслеживать среднюю загрузку CPU
  2. Целевое значение — 70%
2. Поднять загрузку CPU как минимум до 70%
  1. Меняется ли количество экземпляров?
1. Снизить загрузку CPU ниже 70%
  1. Меняется ли количество экземпляров?

### Решение

#### Консоль

1. Перейти в сервис EC2 -> Auto Scaling Groups и открыть вкладку "Automating scaling"
2. Выбрать "Target tracking scaling" в "Policy Type"
3. Установить тип метрики Average CPU utilization
4. Установить целевое значение 70% и нажать "Create"

1. Если используется Amazon Linux 2, нагрузить экземпляр можно так:

```
sudo amazon-linux-extras install epel -y
sudo yum install stress -y
stress -c 4  # предполагается, что у вас 4 CPU
```
2. Да, был добавлен ещё один экземпляр EC2

1. Просто остановить команду stress
2. Да, один из экземпляров EC2 был завершён (terminated)
