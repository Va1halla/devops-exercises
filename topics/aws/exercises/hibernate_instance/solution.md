## AWS EC2 - гибернация экземпляра

### Цели

1. Создать экземпляр с поддержкой гибернации (hibernation)
2. Перевести экземпляр в режим гибернации
3. Запустить экземпляр
4. Как с точки зрения ОС доказать, что экземпляр находился в гибернации?

### Решение

1. Создать экземпляр с поддержкой гибернации
  1. Перейти в сервис EC2
  2. Перейти в instances и создать экземпляр
  3. В "Configure instance" обязательно отметить "Enable hibernation as an additional stop behavior"
  4. В "Add storage" обязательно включить шифрование EBS и убедиться, что размер > объёма RAM экземпляра (потому что при гибернации сохраняется состояние RAM)
  5. Review and Launch

2. Перевести экземпляр в режим гибернации
  1. Перейти на страницу экземпляра
  2. Нажать "Instance state" -> "Hibernate instance" -> Hibernate

3. Instance state -> Start

4. Выполнить команду "uptime", которая покажет, сколько времени система работала
