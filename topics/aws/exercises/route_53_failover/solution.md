## AWS Route 53 - отказоустойчивость (Failover)

### Требования

Работающий веб-экземпляр EC2, для которого в Route 53 определена проверка состояния (health check)

### Цели

1. Создать failover-запись, которая переключается на другую запись, если проверка состояния не проходит
  1. TTL должен быть 30
  2. Связать failover-запись с имеющейся проверкой состояния

### Решение

#### Консоль

1. Перейти в сервис Route 53
2. Нажать "Hosted Zones" в меню слева
3. Выбрать свою hosted zone
4. Нажать "Created record"
5. Ввести "failover" в record name и установить record type в A
6. Ввести IP своего экземпляра
7. Установить политику маршрутизации (routing policy) failover
8. Установить TTL 30
9. Связать с проверкой состояния
10. Добавить ещё одну запись с теми же параметрами, что и предыдущая
11. Нажать "Create records"
12. Перейти к экземпляру EC2 и отредактировать его группу безопасности, удалив правила HTTP
13. Открыть веб-приложение: если оно выводит hostname экземпляра, будет видно, что произошло переключение (failover) и используется другой экземпляр EC2
