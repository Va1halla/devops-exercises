## AWS Route 53 - создание записей

### Требования

Как минимум один зарегистрированный домен

### Цели

1. Создать для своего домена следующую запись:
  1. Record name: foo
  2. Record type: A
  3. Указать какой-нибудь IP в поле value

2. Проверить из оболочки, что созданная запись позволяет найти IP-адрес по доменному имени

### Решение

1. Перейти в сервис Route 53 -> Hosted zones
2. Нажать на своё доменное имя
3. Нажать "Create record"
4. Ввести "foo" в "Record name"
5. Установить "Record type" в A
6. В поле "Value" ввести "201.7.20.22"
7. Нажать "Create records"

1. В оболочке выполнить `nslookup foo.<YOUR DOMAIN>` или `dig foo.<YOUR NAME`
