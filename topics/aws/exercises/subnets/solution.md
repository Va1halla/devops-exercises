# AWS VPC - подсети (Subnets)

## Требования

1. Один только что созданный VPC
2. Регион, в котором больше двух зон доступности

## Цели

1. Создать подсеть в новом VPC
   1. CIDR: 10.0.0.0/24
   1. Имя: NewSubnet1
2. Создать ещё одну подсеть
   1. CIDR: 10.0.1.0/24
   2. Имя: NewSubnet2
   3. AZ, отличная от AZ предыдущей подсети
3. Создать ещё одну подсеть
   4. CIDR: 10.0.2.0/24
   5. Имя: NewSubnet3
   6. AZ, отличная от AZ предыдущих подсетей

## Решение

### Консоль

1. Нажать "Subnets" в разделе "Virtual Private Cloud"
2. Включить фильтр по новому VPC (чтобы не видеть подсети всех остальных VPC). Это можно сделать в меню слева
3. Нажать "Create subnet"
4. Выбрать новый VPC
5. Задать имя подсети "NewSubnet1"
6. Выбрать AZ
7. Установить CIDR 10.0.0.0/24
8. Нажать "Add new subnet"
9. Задать имя подсети "NewSubnet2"
10. Выбрать другую AZ
11. Установить CIDR 10.0.1.0/24
12. Нажать "Add new subnet"
13. Задать имя подсети "NewSubnet3"
14. Выбрать другую AZ
15. Установить CIDR 10.0.2.0/24
