## AWS IAM - Access Advisor

### Цели

Открыть Access Advisor и ответить на следующие вопросы об одном из пользователей:

1. Есть ли сервисы, к которым этот пользователь ни разу не обращался?
2. К какому сервису пользователь обращался последним?
3. Для чего используется / чем полезен Access Advisor?
