## AWS IAM - Access Advisor

### Цели

Открыть Access Advisor и ответить на следующие вопросы об одном из пользователей:

1. Есть ли сервисы, к которым этот пользователь ни разу не обращался?
2. К какому сервису пользователь обращался последним?
3. Для чего используется / чем полезен Access Advisor?

### Решение 

1. Перейти в сервис AWS IAM и нажать "Users" в разделе "Access Management"
2. Выбрать одного из пользователей
3. Открыть вкладку "Access Advisor"
4. Посмотреть, к какому сервису обращались последним, а к каким не обращались никогда

Access Advisor помогает оценить, есть ли сервисы, к которым пользователь не обращается (совсем или нечасто). Это помогает решить, не стоит ли отозвать или изменить часть разрешений.
