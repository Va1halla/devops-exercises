## Сумма

### Цели

1. Написать скрипт, который получает два числа и выводит их сумму
3. Убедиться, что ввод корректен (= от пользователя получены два числа)
2. Протестировать скрипт, запустив его и передав два числа в качестве аргументов 

### Ограничения

1. Использовать функции

### Решение

```
#!/usr/bin/env bash

re='^[0-9]+$'

if ! [[ $1 =~ $re && $2 =~ $re ]]; then
    echo "Oh no...I need two numbers"
    exit 2
fi

function sum {
    echo $(( $1 + $2 ))
}

sum $1 $2
```
