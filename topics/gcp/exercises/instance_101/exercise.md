# Создание инстанса

## Цели

1. Создать VM-инстанс со следующими свойствами
   1. name: instance-1
   2. type: e2-micro
   3. labels:
      1. app: web
      2. env: dev
2. С помощью CLI (gcloud) выполнить следующие операции:
   1. Изменить метку "app" на "db"
   2. Удалить метку "env"
