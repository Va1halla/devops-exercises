# Назначение ролей

## Цели

1. Назначить следующие роли участнику вашей организации
   1. Compute Storage Admin
   2. Compute Network Admin
   3. Compute Security Admin
2. Проверить, что роли назначены

## Решение

### Консоль

1. Перейдите в IAM & Admin
2. Нажмите IAM, а затем кнопку "Add"
   1. Выберите аккаунт участника, которому будут добавлены роли
   2. В поле выбора роли найдите роли, указанные в разделе "Цели", и нажмите "Save"
2. Теперь участник должен иметь возможность перейти в API Compute Engine и увидеть там ресурсы.
