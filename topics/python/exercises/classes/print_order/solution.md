# Порядок вывода

## Цели

1. Каким будет вывод следующего кода?

```python
print(1)
class Car:
    print(2)
    def __init__(self, color):
        print(3)
        self.color = color
    print(4)
print(5)

car1 = Car("red")
car2 = Car("green")
```

## Решение

1.
```
1
2
4
5
3
3
```

3 выводится только в конце, потому что тело функции не выполняется при её определении, а тело класса ВЫПОЛНЯЕТСЯ при определении.
