## Допустимые имена переменных

1. Какие из следующих имён переменных допустимы?

* `x` — допустимо
* `x_and_y` — допустимо
* `x_&_y` — недопустимо
* `2` — недопустимо
* `2nd` — недопустимо
* `_2` — допустимо
* `x-y` — недопустимо

2. Верно или нет? Если определена переменная с именем `var`, то `VAR` — это то же имя, так как Python не чувствителен к регистру — неверно
