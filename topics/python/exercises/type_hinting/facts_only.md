## Только факты

Какие из следующих утверждений об аннотациях типов (type hinting) верны?

1. Аннотации типов — это специальный синтаксис, используемый в объявлениях функций и переменных, чтобы сообщить разработчику информацию о типе переменной
2. Аннотации типов — сравнительно новая возможность Python, появившаяся в Python 3
3. Python принудительно проверяет аннотации типов, то есть переменной с аннотацией типа string можно присвоить целочисленное значение
