# Классы 101 — решение

## Цели

1. Определить класс, который ничего не делает, и назвать его `SomeClass`
2. Создать экземпляр определённого класса и присвоить его переменной `c`
3. Верно или нет? В случае `c.x = 1` `x` — это переменная со значением 1
4. Как получить значение атрибута `x` из предыдущего вопроса?

## Решение

1.

```python
class SomeClass:
    pass
```

2. 

```python
c = SomeClass()
```

3. Неверно. В `c.x` `x` — это атрибут экземпляра `c`, а не переменная
4. `c.x`
