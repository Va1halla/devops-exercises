## Выход из цикла 2

Перебрать заданный список чисел и выйти из цикла, если одно из чисел равно 2 или 4. Если ни одно из этих чисел не встретилось, вывести сообщение об этом.

### Решение

```python
for i in li:
    if i == 2 or i == 4:
        print("Found it!")
        break
else:
    print("Didn't find 2 nor 4")
```
