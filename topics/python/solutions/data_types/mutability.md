## Изменяемость

1. Объясните, что такое изменяемость (mutability)
2. Приведите пример 2 изменяемых и 2 неизменяемых типов данных

1. Изменяемость в Python означает, можно ли изменить значение определённого типа.
   Например, допустим, определена следующая переменная: `x = 2017`
   Если прибавить к ней 5, результатом будет совершенно другой объект, потому что целые числа в Python неизменяемы: `x = 2017 + 5`

2.

Изменяемые:

  * List
  * Dictionary

Неизменяемые:

  * Integer
  * String
